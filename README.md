# موقع لانشر مجاني

صفحة هبوط ثابتة جاهزة للاستضافة على GitHub Pages.

## الملفات الرئيسية
- `index.html` - الصفحة الأساسية.
- `styles.css` - تنسيق الموقع.
- `script.js` - تفعيل زر القائمة في الهواتف.

## كيفية النشر على GitHub Pages
1. أنشئ مستودع جديد على GitHub.
2. انسخ الملفات في المستودع.
3. اذهب إلى إعدادات المستودع `Settings` > `Pages`.
4. اختَر الفرع `main` أو `master` ثم `root` كمصدر.
5. احفظ وانتظر قليلًا حتى يظهر رابط الموقع.

## تعديل المحتوى
- حرّر النصوص في `index.html` لتضيف اسم المنتج والمميزات.
- يمكنك تغيير الألوان في `styles.css`.
- إذا أردت صفحة بلون آخر، عدل المتغيرات في بداية `styles.css`.
